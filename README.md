# SQL Investigation Game

Jogo educacional de investigação em português para aprender SQL resolvendo casos.

## Visão do produto

- No mínimo 200 casos gratuitos.
- Progressão pedagógica baseada em documentação oficial.
- Gamificação com recompensas, conquistas e evolução do jogador.
- Autenticação e progresso persistente.
- Identidade visual própria.
- Deploys de teste pela Vercel.

## Estado atual

O projeto está na fase inicial de definição e estruturação técnica.

## Fluxo de contribuição

O desenvolvimento acontece em branches específicas. Mudanças devem ser revisadas antes de chegar à branch principal.

Convenção sugerida:

- `feat/`: novas funcionalidades.
- `fix/`: correções.
- `chore/`: infraestrutura e manutenção.
- `docs/`: documentação.

Commits seguem o padrão [Conventional Commits](https://www.conventionalcommits.org/).
